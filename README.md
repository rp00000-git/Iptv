# Iptv

Curated public IPTV playlist for Televizo, focused on Israeli channels and English channels in documentary, science, nature, history, crime, news, movies and series.

## Televizo URLs

- Playlist: `https://raw.githubusercontent.com/rp00000-git/Iptv/main/playlist.m3u`
- EPG: `https://raw.githubusercontent.com/rp00000-git/Iptv/main/epg.xml`

The GitHub Action refreshes the playlist daily and removes English streams that fail the automated availability check. Israeli channels are retained because some may be geo-restricted outside Israel.
